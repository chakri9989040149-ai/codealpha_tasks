## 📖 About the Repository

This repository contains all the tasks I completed as part of the **CodeAlpha Full Stack Development Internship (1 – 30 November 2026)**. Each project is a self-contained application that covers the complete development cycle: user interface design, backend logic, database integration, and deployment-ready structure.

The goal of these projects was to apply real-world full stack concepts and build applications that mirror the products people use every day.

## ⚙️ Getting Started

### Prerequisites
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (v16 or later)
- A code editor such as VS Code

### Clone the repository

```bash
git clone https://github.com/chakri9989040149-ai/codealpha_tasks.git
cd codealpha_tasks
```

### Run a project

```bash
# Go into the project you want to run
cd CodeAlpha_EcommerceStore      # or CodeAlpha_SocialMedia / CodeAlpha_ProjectManagementTool

# Install dependencies
npm install

# Start the application
npm start
```

Then open **http://localhost:3000** in your browser.

> ✏️ *If a project uses a different start command or port, or needs a `.env` file, note it in that project's own folder.*
